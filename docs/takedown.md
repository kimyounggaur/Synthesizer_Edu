# 매뉴얼 링크 이의·정정·삭제 절차

공개 접수 창구: [GitHub 이슈로 요청하기](https://github.com/kimyounggaur/Synthesizer_Edu/issues/new?title=%5B%EB%A7%A4%EB%89%B4%EC%96%BC%20%EC%9D%B4%EC%9D%98%2F%EC%82%AD%EC%A0%9C%20%EC%9A%94%EC%B2%AD%5D&labels=takedown)

권리자와 이용자는 저작권, 잘못된 공식 링크, 잘못된 모델 연결, 개인정보 또는 기타 정당한 사유로 정정·삭제를 요청할 수 있다. 비공개 정보가 포함된 경우 공개 이슈에는 세부 내용을 쓰지 말고 최초 접수 후 제공되는 비공개 연락 경로를 사용한다.

## 서비스 수준

1. 요청 접수 후 24시간 안에 접수 여부와 담당 상태를 회신한다.
2. 진위 확인 중에는 관련 소스를 `suspended`로 전환해 신규 수집을 막는다.
3. 관련 L2 로컬/R2 원본 캐시를 삭제한다.
4. 공개 L1 링크를 `dead` 또는 비공개 상태로 전환하고 정정·삭제 범위를 판단한다.
5. 처리자, 시각, 대상, 사유를 감사 로그에 남긴다.
6. 요청자에게 최종 조치와 남아 있는 공개 메타데이터를 알린다.

앱 관리자 화면의 “게시 중단·원본 캐시 삭제” 작업은 2–5단계를 한 번에 수행한다. Git 이력에 원본 파일을 저장하지 않으므로 저장소에서 원본을 제거하는 별도 절차는 발생하지 않아야 한다. 만약 정책 위반 파일이 발견되면 즉시 공개 배포를 중단하고 저장소 관리자와 함께 이력 정리 범위를 결정한다.
