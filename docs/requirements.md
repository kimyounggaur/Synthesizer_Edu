# 설계서 v1.1 대응

문서에 포함된 개발자 프롬프트는 별도 실행 권한으로 취급하지 않았습니다. 사용자의 실제 요청인 자율 개발 범위에 따라 제품 요구사항을 구현했습니다. 문서의 ‘실물 검증’은 소프트웨어 테스트나 자동 승인으로 대신하지 않았습니다.

| 요구사항                | 구현                                                        | 현재 경계                              |
| ----------------------- | ----------------------------------------------------------- | -------------------------------------- |
| F01 촬영·파일·직접 입력 | `identify-screen`, 모델 후보/확정                           | 카메라 권한은 촬영 시작 때 요청        |
| F02 OCR·후보            | 서버 Google Vision 어댑터, 브랜드·접미사 보존               | 공급자 키 미연결, 직접 입력 정상 사용  |
| F03 지원 상태 분리      | 카탈로그/문헌/실물 검수 상태 분리                           | 실제 악기 안내는 모두 준비 중          |
| F04 목적별 홈           | 첫 소리 + 소리 선택/듀얼/스플릿                             | 상세 8개는 전체 학습에서 접근          |
| F05 단계 안내           | L00–L07, 1행동/결과/도움/마무리                             | 화면 연습, 실제 절차 공개 안 함        |
| F06 버튼 찾기           | SVG 목표, 힌트, 자유 탐색, 이름 목록                        | 실물 조작 감지 아님                    |
| F07 문제 해결           | T01–T05와 버튼/모델 도움                                    | 저장·초기화·무조건 EXIT·전원 차단 제외 |
| F08 진도·재개           | IndexedDB, 모의 상태 저장, 재확인                           | 이 기기 로컬 기록, 동기화 P1           |
| F09 안전 보호           | 정확한 모델, R0 제한, 게시 검수, 회수                       | 미검수 실제 조작 차단                  |
| F10 오프라인            | 해시·원자적 포인터·동시 큐·직접 경로                        | 명시적으로 저장한 화면 연습만          |
| F11 CMS                 | 서버 관리자, JSON 초안, 같은 렌더러, 검수·게시·회수         | 타인 검수 없는 게시 차단               |
| F12 접근성·오류         | 키보드, Base UI, 목록, 확대 버튼, reduced-motion, 상태 안내 | 실기기/스크린리더 적합성 시험 미수행   |
| 36장 시각 학습          | 전면·후면·측면, 모션, 확대, 패널 상태와 목표 강조 분리      | 사진 기반 실물 트레이싱 미확보         |

## 출시 범위

P0-A 소프트웨어 흐름과 P0-B 화면 연습·관리 기반을 구현했습니다. P0-B의 **실제 악기 대상 공개 시험**은 외부 OCR 연결·실물 패널 검수·초보자 관찰 시험이 충족되지 않았으므로 완료 처리하지 않습니다.

P1(계정 동기화, 추가 기종, 강사 QR, 근거 검색)과 P2(AR, MIDI, 음성 명령)는 문서에 명시된 후속 범위로 남깁니다.
