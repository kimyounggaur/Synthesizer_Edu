# 콘텐츠·패널 검수 인계

현재 모델: Roland JUNO-DS61. 상태: `literature_checked`, `hardwareVerified:false`, `actualBbox:null`. 펌웨어/실물 검수자/장비 확보 정보는 제공되지 않았습니다.

공식 문헌: https://static.roland.com/assets/media/pdf/JUNO-DS_e02_W.pdf (인쇄 2·3·5·6·7쪽). 공식 문헌 그림을 확인했으며 이는 실물 악기 검수와 다릅니다.

대조 반영 사항:

- 범용 CATEGORY 예시를 실제 `[PIANO]` 등 카테고리 버튼으로 구체화.
- `[KEYBOARD/ORGAN]`, `[GUITAR/BASS]`, `[ORCHESTRA]` 라벨 적용. 독립된 ORGAN/STRINGS 버튼을 만들지 않음.
- KEYBOARD 영역의 SPLIT/DUAL/SUPER LAYER, ARPEGGIO/KEY TOUCH/PATCH/PERFORM, TRANSPOSE/OCTAVE 배열.
- POWER는 측면이 아닌 후면. DC IN 오른쪽. 좌우 측면에는 미확인 조작부를 생성하지 않음.
- PATCH/PERFORM이 꺼진 상태가 Patch 모드이며 이미 꺼진 토글을 다시 누르라는 지시를 하지 않음.
- TRANSPOSE를 유지한 뒤 OCTAVE를 누르는 순서를 구분. 단독 탭으로 완료되지 않음.
- LOWER LEVEL은 파트 음량 조작임을 명시. 실제 저장/복원은 자동 처리하지 않음.

실물 공개 안내로 확장하기 전에:

1. 정확한 SKU·패널·지역·펌웨어와 현재 모드를 기록합니다.
2. 전면·후면·측면 자산의 권리 및 해상도·좌표를 확인합니다.
3. 각 단계의 실제 라벨·시작값·결과·예외·복구를 실물에서 재현합니다.
4. R1/R2 절차는 상태 조건·관측 응답·원래 값·복구 조건 및 온라인 회수 정책을 별도로 계약에 추가합니다. 현재 R0 렌더러에 값을 바꿔 끼워 게시하지 않습니다.
5. 작성자와 다른 검토자의 서명·일시·근거 기록을 남깁니다.
6. 초보자 관찰 시험, 버튼 위치 대조, 브라우저·접근성 검증 후 실제 학습 모드를 출시합니다.

어떤 단계도 실물 검수를 자동 완료한 것으로 표시하지 않습니다. 관리자 화면의 검수 기록은 인증된 검토자가 실제 증거를 입력할 때만 사용할 수 있습니다.
